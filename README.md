# 🌡️ Temperature Converter

A responsive temperature converter built using HTML, CSS and JavaScript.

## Features

- Celsius to Fahrenheit and Kelvin conversion
- Fahrenheit to Celsius and Kelvin conversion
- Kelvin to Celsius and Fahrenheit conversion
- Input validation
- Enter key support
- Clean and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter a temperature value.
2. Select the unit.
3. Click **Convert Temperature**.
4. View the converted values.

You can also press **Enter** after entering the temperature.
